Lost and Found App (Task 7.1)
This is a simple Android app built with Java, XML, and SQLite.

Features
Create a lost/found advert
Required image upload for each post
Automatic date/time stamp when saving
View all posts in a list
Filter posts by category
Open item details and remove the post
Tech
Java
Android XML layouts
SQLite (SQLiteOpenHelper)
App flow
Home screen:
CREATE A NEW ADVERT
SHOW ALL LOST & FOUND ITEMS
Create screen:
Fill all fields
Select required image
Press SAVE
List screen:
View all items
Filter by category
Tap an item to open details
Detail screen:
See full item info
Press REMOVE to delete
